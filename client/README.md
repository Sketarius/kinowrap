# Kinowrap page

This folder is the Angular front end of Kinowrap. See the [main README](../README.md) for setup and usage.

- `npm install`, then `npm start` runs the dev server on http://localhost:4200 (it forwards API calls to the Kinowrap server on port 3000 using `proxy.conf.json`).
- `npx ng build` makes a production build in `dist/`.
